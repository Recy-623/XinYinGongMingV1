# 心印共鸣 V6 · 长期陪伴

一个本机运行的长期陪伴角色客户端。它把固定人设、按需检索的长期记忆、独立世界观和历史分支分层管理，在控制 Token 成本的同时尽量维持跨会话一致性。

## V6 重点

- `xinyin-card-v6` 的 `companion` 模式，与短期语 C 卡明确隔离。
- 角色、人设、历史分支和配置保存在本机。
- 长期记忆保存在独立 SQLite 数据库 `xinyingongming-companion.sqlite3`。
- 只在当前话题相关时发送少量记忆，记录使用次数并支持有效、已解决、已过期、已取代和永不提及状态。
- 关系阶段由模型提出、用户确认；未确认提案不会当作事实。
- 记忆整理按事件和上下文阈值触发，不固定每轮增加一次模型请求。
- 支持独立 `xinyin-worldbook-v1` 世界观，按关键词检索相关条目，不把整本设定常驻提示词。
- 首页可设置每轮 50–1000 字的回复偏好；接近标准长度时要求自然收束，最多浮动约 20%。
- 每条角色回复可提交一次性意见并重写；意见不会进入聊天历史或长期记忆，重写稿会经过独立验收。
- 默认检查每轮回复是否误读用户、虚构事实、越过使用者心理与行动边界，发现问题会自动重写。
- Token 情况展示独立记录各类请求的输入、输出、缓存命中和耗时元数据，不保存提示词、正文、密钥或推理内容。
- 保留聊天记录导入、关系蒸馏、历史锚点与“刻舟求剑”分支；分支模拟不会污染真实时间线的长期记忆。
- API Key 只保存在当前运行内存，不写入数据库、角色卡或备份。

## 数据位置

Windows 安装版使用 Tauri 应用数据目录。主数据库文件名固定为：

```text
xinyingongming-companion.sqlite3
```

数据库与短期语 C 版本的 `xinyingongming-r18.sqlite3` 完全分离。
两版还使用不同的应用标识，因此不会共享 WebView 本地配置。功能迁移只允许复制通用代码和空数据结构，不迁移短期语 C 的角色、世界观、聊天、记忆或日志。

## 隐私边界

- 使用 Ollama 时，请求留在本机模型服务。
- 使用云 API 时，本轮必要提示、相关记忆与对话上下文会发送给用户配置的服务商。
- 微信和 QQ 连接器只读取用户明确授权的导出或本机只读接口。
- 仓库、发行包和分享包不得包含任何实际聊天、角色实例、世界观实例、数据库、日志、备份或密钥。
