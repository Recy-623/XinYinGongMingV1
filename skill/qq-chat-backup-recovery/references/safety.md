# 安全与隐私边界

## 授权范围

- 只处理用户本人有权访问的 QQ 账号、备份和联系人聊天。
- 只导出用户明确指定的联系人；若目标不明确，先停下确认。
- 开始时只读检查。安装软件、创建实例、恢复备份等状态变更需要当前任务中已有明确授权。

## 凭据与登录

- 密码、扫码、短信验证码和设备确认只由用户本人输入。
- 不读取、复制、截图、记录或导出登录令牌、Cookie、二维码、设备密钥、数据库密钥和完整应用数据。
- 临时秘密若确有必要，只允许在本机进程内短暂使用；不得出现在命令行参数、脚本源码、日志、命令历史或最终报告中。

## 数据处理

- 原始电脑备份和模拟器源数据库保持只读。
- 解密、WAL 合并和解析只在带时间戳的工作副本上进行。
- 默认本地处理并使用本地 Ollama。未经额外、明确授权，不把数据库、聊天正文、导出 JSON 或角色素材上传到云端。
- 数据最小化：优先只保留 `sender`、`timestamp`、`content` 等导入必需字段；不要生成整个账号的明文 SQL 转储。
- 日志和最终报告只写路径、数量、时间范围、哈希和错误类型，不打印聊天正文、QQ 号、内部 UID、URL 或二进制载荷。

## 工具与安装

- 使用当前版本、来源清楚、许可证明确且经过审阅的工具；QQ 安装包优先来自官方来源。
- 记录下载来源、版本和 SHA-256，但不要把用户凭据写入清单。
- 新建独立模拟器实例，与用户日常模拟器、实体手机和其他账号隔离。
- ADB 操作必须显式绑定目标实例，并在执行前核对设备序列号和 QQ 包名。

## 禁止行为

- DLL/Frida 注入、Hook QQ 进程、进程内存扫描、键盘记录、凭据窃取或绕过账号安全。
- Root 用户的实体手机，或关闭 SELinux、Defender、杀毒软件、防火墙和系统安全更新。
- 创建后门、监听端口、常驻服务、启动项或未声明的计划任务。
- 导出会话令牌、Cookie、登录二维码、设备密钥、整个应用私有目录或无关联系人的数据。
- 把原始聊天、数据库或导出 JSON 上传到未知网站、网盘、公共分析服务或远程大模型。
- 未经批准自动删除备份、模拟器实例、快照、导出文件或工具。

## 解密边界

1. 先检查快照是否已经是普通 SQLite；能直接读取就跳过解密。
2. 只有经过代码审阅的离线方案才可用于复制出的数据库快照。
3. 优先通过标准输入、受限临时文件或进程内变量传递必要秘密，使用后清理，不在输出中回显。
4. 如果当前 QQ 版本只能依赖注入、内存读取、安全降级或未知闭源破解工具，停止并说明“安全边界内暂不可完成”。

## 立即停止的情况

- 备份归属、用户权限或目标联系人无法确认。
- 工具校验失败、来源不明、出现异常联网或持久化行为。
- 快照不一致、数据库损坏，继续可能影响唯一副本。
- 操作开始指向实体设备、非专用模拟器实例或其他 QQ 账号。
- 输出可能包含密码、令牌、密钥或非目标联系人的大量隐私数据。
