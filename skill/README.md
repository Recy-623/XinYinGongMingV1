# 项目技能目录

这里统一收纳能够规模化帮助心印共鸣开发、数据处理、测试或交付的 Codex Skill。

## 目录约定

- `skill/<skill-name>/`：可维护、可审阅的技能源文件。
- `skill/<skill-name>/*.skill`：与源文件放在同一技能子目录内，供下载、分享或安装。
- 技能内部名称使用小写英文和连字符，展示名称和安装包可以使用中文。
- 新增或更新技能时，需要校验 `SKILL.md`、测试配套脚本，并记录安装包 SHA-256。
- 不得提交聊天原文、账号、UID、登录凭证、数据库密钥、令牌或包含用户隐私的测试产物。

## 已收录技能

### distill-chat-relationship

从用户有权访问的双方聊天记录中：

1. 给出一句话关系判断和证据置信度。
2. 提取带具体时间、变化概括和替代解释的关系转折时间线。
3. 生成不含聊天原文、可直接导入心印共鸣的 `xinyin-card-v4` 角色卡。

调用示例：

```text
使用 $distill-chat-relationship 分析这份双方聊天记录，给出一句话关系判断、转折时间线并生成心印共鸣角色卡。
```

安装包：`distill-chat-relationship/心印共鸣-聊天关系判断转折分析与角色卡.skill`

SHA-256：`32388020958B83AA347B52F77608310697980CE50493F0FBE18C85B5835EA1AC`
