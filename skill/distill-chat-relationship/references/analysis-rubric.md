# 关系判断与转折分析准则

## 证据层级

### 强证据

- 双方直接确认关系标签、承诺或边界。
- 双方对现实共同计划进行持续协商并实际跟进。
- 同一模式跨多个时间段重复出现，且双方行为相互呼应。
- 冲突后出现明确解释、边界重置和可观察的行为改变。

### 中等证据

- 互动从单一事务扩展到日常、自我披露、照料和情绪支持。
- 双方持续主动发起、等待、优先安排或在长空窗后重连。
- 稳定的亲昵称呼、陪伴需求、轻度嫉妒或调情，但没有直接确认。

### 弱证据

- 单次玩笑、表情、醉酒表达、转发内容或第三方故事。
- 游戏中的“情缘”“绑定”“老婆/老公”等角色化称呼。
- 单方陈述且没有对方回应或后续行为支持。
- 只凭消息数量、回复速度或某个关键词。

## 关系标签

- `普通熟人`：以事务或偶发互动为主，缺少稳定自我披露。
- `朋友`：存在双向交流和支持，但亲密度、优先级期待有限。
- `亲近朋友 / 知己`：稳定分享脆弱、日常和重要事件，关系具有持续性。
- `高亲密活动搭档 / 情绪陪伴型搭档`：共同活动是连接器，同时承接明显陪伴需求和情绪调节。
- `暧昧 / 关系未定义`：有双向调情、亲密期待或排他倾向，但没有共同确认；必须写明未确认。
- `恋人 / 稳定亲密关系`：需要双方直接确认或等价的持续共同承诺；不能只靠行为猜测。
- `降温中的旧友 / 间歇联系人`：过去亲密，近期主要是低频重连或具体求助。

标签可以组合，例如“高亲密线上朋友 / 情绪陪伴型游戏搭档，带阶段性暧昧感但未确认恋爱”。

## 判断维度

1. 频率：活跃天数、消息量、会话数量和阶段变化。
2. 互惠：合并连续短句后双方轮次是否接近，不能只看碎片消息数。
3. 主动性：谁开启日常会话，谁在 3 天、7 天和更长空窗后重连。
4. 话题广度：是否从事务扩展到工作、家庭、健康、脆弱和未来。
5. 陪伴与优先级：是否持续邀请、等待、要求回应或在意被排除。
6. 冲突与修复：冲突是否增加情绪距离，还是产生更明确边界和修复。
7. 现实承诺：是否存在双方确认、线下计划、关系标签或排他协商。
8. 当前状态：最后阶段是否延续高峰，还是只保留熟悉感和工具性信任。

## 转折点判定

一个时间点只有同时满足以下至少两项，才建议列为转折：

- 活跃度或主动性显著改变。
- 话题深度或关系角色改变。
- 出现关系确认、边界设置、冲突或修复。
- 后续至少一个阶段延续了改变。
- 长空窗后的重连方式与此前不同。

时间线项包含时间、转折前、观察变化、转折后、关系意义、置信度和替代解释。

## 置信度

- `90–100%`：多种独立证据一致，替代解释很弱。
- `75–89%`：主要结论稳定，但仍有记录缺失或语境限制。
- `55–74%`：存在合理信号，也有明显反证或歧义。
- `30–54%`：只能作为候选解释，不能写成主结论。
- `<30%`：不应固化进角色卡事实，只能放入 `uncertainties`。

置信度描述“证据对这个结论的支持”，不是对真实人物内心的概率测量。

## 固定交付格式

一句话：`最可能是「关系标签」：一句证据概括；对更亲密标签的主要保留是……（置信度：84%）。`

时间线使用表格列出时间、关系变化、影响、置信度和替代解释，保持 3–8 行。

证据边界分别列出最强支持证据、主要反证、不能判断的内容、语义审阅数量和全量消息数量。
